# java-racingcar-precourse

## Ⓜ️기능 요구사항
- 사용자로부터 경주할 자동차 이름과 시도할 횟수를 입력받는다.
  - 이름은 5자 이하만 가능하다.
  -  ✏️ 이름은 최소 1자 이상이어야 한다.
  -  ✏️ 이름은 영문자만 가능하다.
  -  ✏️ 이름은 중복될 수 없다.
  -  ✏️ 총 이름의 개수는 2 ~ 10 사이의 범위여야 한다.
  -  ✏️ 시도 횟수는 1 ~ 10 사이의 숫자값만 가능하다.
  - 시도 횟수는 오직 숫자만 가능하다.
- 이름은 쉼표 기준으로 구분해 파싱한다.
- 자동차는 이름을 가지며 전진 또는 멈출 수 있다.
  - 0 ~ 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우에 전진할 수 있다.
- 차수별로 실행 결과를 출력한다.
    ```
    pobi : --
    woni : ----
    jun : ---
    ```
- 게임 종료 후 우승자를 출력한다.
  - 단독 우승인 경우
    ```
    최종 우승자 : pobi
    ```
  - 공동 우승인 경우
    ```
    최종 우승자 : pobi, jun
    ```

( ✏️ : 본인이 설정한 추가 요구사항)
